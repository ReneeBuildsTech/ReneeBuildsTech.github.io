P3 — SIEM

Okta AWS SIEM Pipeline

Enterprise equivalent: Splunk ES · Microsoft Sentinel · Okta ThreatInsight

Complete

Hybrid local-to-cloud SIEM pipeline ingesting Okta system logs via a cron-driven EC2 poller (every 5 min, DynamoDB cursor state) into Kinesis Firehose and an S3 data lake. Lambda triggers on EventBridge failed-login rules, generates AI risk narratives via Amazon Bedrock (Claude Sonnet 4.6), and routes alerts via SNS. Multi-region CloudTrail with ApiCallRateInsight captures AWS control plane activity. QuickSight SOC dashboard connected to Athena dataset. Three GitHub Actions workflows: push-triggered deploy, PR validation (fmt + validate + plan), and scheduled daily drift detection — all running on a self-hosted EC2 runner. Full Terraform infrastructure with remote state in S3.

P4 — Audit

IAM Policy Auditor AI

Enterprise equivalent: AWS IAM Access Analyzer · Wiz · Prisma Cloud

Complete

Audits AWS IAM policies for least-privilege violations — wildcard actions, missing MFA conditions, stale credentials, privilege escalation paths — across 6 real policies including a self-scoring CRITICAL finding on its own auditor policy. AI-generated risk narratives via Amazon Bedrock (Claude Sonnet 4.6) with prompt injection defense via _sanitize_input(). Async job engine decouples scan execution from the Flask request path. CRITICAL findings publish to the shared P3 SNS topic. Cross-project Athena queries correlate P3 SIEM events with P4 IAM findings. QuickSight "IAM Security Posture" dashboard. Cron scheduler fires every 6 hours.

GRC1 — Certification

Access Certification Platform

Enterprise equivalent: SailPoint IdentityNow · Saviynt · Any IGA Platform

Complete

AI-hardened identity certification pipeline pulling user and role data from Keycloak, evaluating MFA compliance via Amazon Bedrock (Claude Sonnet 4.6), writing immutable audit evidence to SQLite, and firing SNS REVOKE alerts for non-compliant identities. Upstream parallel inference via ThreadPoolExecutor at campaign launch eliminates runtime timeout risk. Flask dashboard on port 5001 provides reviewer UI and JSON API. Maps directly to PCI DSS Req 8.4.2 — MFA for all non-console CDE access.

GRC2 — Monitoring

Compliance Monitor

Enterprise equivalent: ServiceNow GRC · Archer · Any Continuous Compliance Platform

Complete

Five-layer AI compliance pipeline ingesting AWS Config and EventBridge drift notifications via Lambda into the shared S3 data lake, generating risk narratives via Amazon Bedrock (Claude Sonnet 4.6) with <compliance_context> XML isolation defending against indirect prompt injection, and surfacing findings through a Flask reviewer dashboard on port 5002. ThreadPoolExecutor reduces 3-finding batch from ~27s to ~9s. Idempotent INSERT OR REPLACE with 7-hour lookback over a 6-hour cron cadence eliminates duplicate findings. Maps to PCI DSS Req 6.4.3 (script integrity) and Req 10.4.1.1 (automated audit log review). Shares S3, SNS, Glue, and Athena infrastructure with P3 and P4.
