How This Site Is Hosted

Architecture

ReneeBuilds.com is a static site hosted on Google Cloud Platform, as part of the Multicloud Identity Governance & Entitlement Engine project.

Stack

  • Hosting: GCP Cloud Storage (static website)
  • DNS: Cloudflare (CNAME → c.storage.googleapis.com, DNS-only)
  • Security headers: a Cloudflare response-header transform rule (HSTS, CSP, X-Content-Type-Options) applies to every request via Cloudflare's proxy — confirmed live on both the apex and www. GCS has no native HTTPS for custom domains, so Cloudflare terminates TLS at the edge in "Full" mode; because "Full" validates only that the origin presents a valid certificate rather than that it matches the hostname, the Cloudflare→GCS backend hop is also encrypted using GCS's own certificate. Genuinely end-to-end encrypted, no unencrypted-hop tradeoff.
  • Deploy pipeline: GitHub Actions
  • Authentication: Workload Identity Federation, scoped to this repo's main branch specifically — a token minted anywhere else is rejected before it reaches GCP
  • Credentials stored: zero long-lived keys anywhere in the pipeline
  • IaC: Terraform (GCP resources + Cloudflare DNS + security headers), labeled and cost-tracked
  • Terraform state: AWS S3 remote backend

A Deliberate Exception

The hosting bucket is intentionally publicly readable — that's what makes static website hosting work. Every other guardrail (versioning, least- privilege deploy SA, branch-scoped WIF) is layered around that one necessary exception rather than pretending it isn't there.
